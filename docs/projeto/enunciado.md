# Enunciado do Trabalho Final

Para a realização do trabalho final, você deve inicialmente projetar as
funcionalidades de um **jogo** que será escrito em **JavaScript** e executado
em um navegador Web.
{: .fs-3 }

Existem vários exemplos de jogos simples que podem ser implementados em
JavaScript, como damas, *Space Invaders*, *Flappy Bird*, jogo da memória e
*Snake*, entre muitos outros. Além dessas opções, você também pode propor um
jogo original de sua autoria: os estudantes têm liberdade criativa para
tentar algo novo.
{: .fs-3 }

Caso você não se sinta confortável para criar um jogo do zero, existem
diversos *frameworks* de jogos, como o [Phaser.io](https://phaser.io/), que
oferecem vários exemplos prontos para servir de ponto de partida. Também há
vídeos no YouTube que ensinam a desenvolver partes de um jogo. Nesses casos,
o(a) estudante deve seguir a documentação do *framework* ou o vídeo até o
final e, em seguida, **acrescentar pelo menos três funcionalidades
adicionais** às apresentadas na referência utilizada, **citando
explicitamente a fonte** (documentação, tutorial ou vídeo) consultada.
{: .fs-3 }

## Entrega da proposta em PDF

Antes de iniciar a implementação, cada estudante deve entregar um
documento em **PDF** descrevendo a proposta do jogo, contendo pelo menos:
{: .fs-3 }

* **Conceito do jogo**: uma descrição geral do jogo, incluindo tema, objetivo
  do jogador e contexto/narrativa (quando houver).
{: .fs-3 }

* **Mecânicas**: como o jogo funciona na prática: controles, regras,
  condições de vitória/derrota, pontuação, níveis de dificuldade, entre
  outros elementos que definem a jogabilidade.
{: .fs-3 }

* **Lista de funcionalidades a serem desenvolvidas**: uma lista objetiva das
  funcionalidades planejadas para a versão final do jogo.
{: .fs-3 }

* **Imagem(ns) ilustrativa(s)**, se necessário: esboços, telas de referência,
  *mockups* ou imagens que ajudem a visualizar a ideia do jogo (não é
  obrigatório ter arte final, um rascunho ou referência visual já é
  suficiente).
{: .fs-3 }

* **Referências**: lista de fontes consultadas (documentação, tutoriais,
  vídeos, *frameworks*, jogos que serviram de inspiração, etc.).
{: .fs-3 }

## Requisitos gerais

* O jogo deve ser implementado em **JavaScript** e executado em um
  navegador Web, podendo utilizar HTML e CSS livremente.
{: .fs-3 }

* É permitido o uso de *frameworks* ou bibliotecas de jogos (como o
  Phaser.io), desde que a origem de qualquer código ou template utilizado
  como base seja **referenciada** no trabalho.
{: .fs-3 }

* Caso o jogo seja baseado em um tutorial, vídeo ou exemplo de terceiros, é
  obrigatório implementar **no mínimo três funcionalidades novas**, que não
  constem na referência original, além de creditar a fonte utilizada.
{: .fs-3 }

* Jogos originais (criados do zero, sem seguir um tutorial específico) têm
  liberdade total de escopo, desde que apresentem complexidade compatível
  com os conceitos trabalhados na disciplina.
{: .fs-3 }
